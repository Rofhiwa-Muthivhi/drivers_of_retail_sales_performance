### Missing Values

- Before analysis, I checked each dataset for missing values to identify any columns that might require further cleaning.
- All columns in the Sales, Stores, and Features datasets were examined for NULL values to confirm that the data was complete and ready for analysis.

- The results showed that no missing values were present in any of the three datasets. This is because the missing values found in the original raw dataset had already been handled during the data cleaning stage.
- The Features dataset originally contained NA values, particularly in the MarkDown columns and selected economic indicators, but these were addressed before the exploratory analysis was carried out.
